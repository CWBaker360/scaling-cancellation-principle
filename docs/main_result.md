# \# Main Results

# 

# Assume

# 

# \\\[

# Q-Q\_N

# =

# C\_2N^{-2}

# \+

# C\_4N^{-4}

# \+

# O(N^{-6}).

# \\]

# 

# For fixed \\(k\\ge2\\), define

# 

# \\\[

# \\widehat Q\_{N,k}

# =

# \\frac{k^2Q\_{kN}-Q\_N}{k^2-1}.

# \\]

# 

# Then

# 

# \\\[

# Q-\\widehat Q\_{N,k}

# =

# \-\\frac{C\_4}{k^2}N^{-4}

# \+

# O(N^{-6}).

# \\]

# 

# Thus the leading \\(N^{-2}\\) term is removed without knowing \\(C\_2\\); only its

# known scale transformation \\(k^{-2}\\) is required.

# 

# More generally, suppose

# 

# \\\[

# Q-Q\_N

# =

# \\sum\_{r=1}^{s+1} C\_{2r}N^{-2r}

# \+

# O(N^{-2s-4}),

# \\]

# 

# and use the geometric scale nodes

# 

# \\\[

# N,\\ bN,\\ldots,b^sN.

# \\]

# 

# The unique Lagrange weights cancelling the first \\(s\\) even-power terms yield

# 

# \\\[

# Q-\\widehat Q\_N^{(s)}

# =

# (-1)^s C\_{2s+2}b^{-s(s+1)}N^{-2s-2}

# \+

# O(N^{-2s-4}).

# \\]

# 

# For tripling and \\(s=2\\),

# 

# \\\[

# \\widehat Q\_N^{(2)}

# =

# \\frac{Q\_N-90Q\_{3N}+729Q\_{9N}}{640},

# \\]

# 

# which cancels both the \\(N^{-2}\\) and \\(N^{-4}\\) terms.
