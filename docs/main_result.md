# Main Results

Assume

\[
Q-Q_N
=
C_2N^{-2}
+
C_4N^{-4}
+
O(N^{-6}).
\]

For fixed \(k\ge2\), define

\[
\widehat Q_{N,k}
=
\frac{k^2Q_{kN}-Q_N}{k^2-1}.
\]

Then

\[
Q-\widehat Q_{N,k}
=
-\frac{C_4}{k^2}N^{-4}
+
O(N^{-6}).
\]

Thus the leading \(N^{-2}\) term is removed without knowing \(C_2\); only its
known scale transformation \(k^{-2}\) is required.

More generally, suppose

\[
Q-Q_N
=
\sum_{r=1}^{s+1} C_{2r}N^{-2r}
+
O(N^{-2s-4}),
\]

and use the geometric scale nodes

\[
N,\ bN,\ldots,b^sN.
\]

The unique Lagrange weights cancelling the first \(s\) even-power terms yield

\[
Q-\widehat Q_N^{(s)}
=
(-1)^s C_{2s+2}b^{-s(s+1)}N^{-2s-2}
+
O(N^{-2s-4}).
\]

For tripling and \(s=2\),

\[
\widehat Q_N^{(2)}
=
\frac{Q_N-90Q_{3N}+729Q_{9N}}{640},
\]

which cancels both the \(N^{-2}\) and \(N^{-4}\) terms.
