# Main Result

Assume

\[
Q-Q_N=C_2N^{-2}+C_4N^{-4}+O(N^{-6}).
\]

For fixed \(k\ge2\), define

\[
\widehat Q_{N,k}
=
\frac{k^2Q_{kN}-Q_N}{k^2-1}.
\]

Then

\[
Q-\widehat Q_{N,k}
=
-\frac{C_4}{k^2}N^{-4}+O(N^{-6}).
\]

Thus the leading \(N^{-2}\) term is removed without knowing \(C_2\); only its
known scale transformation \(k^{-2}\) is used.
