# \# Abstract

# 

# This paper develops a fixed-scale scaling-cancellation framework for geometric

# approximations admitting even-power asymptotic expansions. Richardson-type

# linear combinations of approximants at related resolutions cancel successive

# terms in the expansion and raise the asymptotic order of accuracy.

# 

# The revised manuscript begins with the two-scale theorem and then derives the

# unique multi-scale Lagrange weights for arbitrary fixed scale nodes. For the

# geometric family

# 

# \\\[

# N,\\ bN,\\ b^2N,\\ldots,b^sN,

# \\]

# 

# the surviving leading error is

# 

# \\\[

# Q-\\widehat Q\_N^{(s)}

# =

# (-1)^s C\_{2s+2} b^{-s(s+1)}N^{-2s-2}

# \+

# O(N^{-2s-4}).

# \\]

# 

# The same hierarchy is expressed recursively as a fixed-base

# Richardson-style ladder and applied to polygonal approximation of \\(\\pi\\)

# and, conditionally on a cited companion factorization, to ellipse perimeters.

# 

# The paper also distinguishes fixed-resolution scale cancellation from the

# nonlinear proportional-subtended residual law

# 

# \\\[

# \\mathscr R\_{a,b}(e)

# =

# \-\\frac{a^2-b^2}{24a^2}e^3

# \+

# O(e^5).

# \\]

# 

# The contribution is not a claim of new Richardson-Romberg theory, but a

# geometric organization of the cancellation hierarchy and its relation to a

# separate cubic residual-refinement mechanism.
